# LOA 튀르크 (트래쉬토크판)

Lines of Action 엔진 **튀르크**와 두는 웹 게임. 튀르크는 판 위쪽 가장자리 뒤에서 머리만 내밀고 좌우로 알짱거리는 동그란 놈이다. 말이 많다. 판세를 보고 비꼬고, 틈나면 잡학을 늘어놓는다.

화면 전체가 스케치북 낙서처럼 생겼다. 종이 바탕에 펜으로 그은 판, 빗금 친 칸, 손으로 칠한 말, 형광펜으로 표시한 마지막 수, 빨간 펜으로 찍은 갈 수 있는 칸. 글씨는 손글씨 폰트(Gaegu, Google Fonts)다.

브라우저로 `index.html`을 열면 된다. 설치할 것 없다.

## 파일

- `engine.js`: LOA 엔진. [loa-turk](https://github.com/fishilyfishyfish/loa-turk)의 `LoaEngine`과 자기대국으로 튜닝한 가중치를 그대로 떼어 왔다. 알파베타(PVS) 탐색, 치환표, 널무브, LMR, 반복 심화, 24개 항목 평가. 페이지가 이 함수로 Web Worker를 만들어서 생각하는 동안 화면이 멈추지 않는다.
- `characters.js`: 튀르크 생김새(SVG)와 대사 목록. 대사는 loa-turk에서 말풍선을 빼기 전(커밋 75777c8 직전)에 있던 목록에서 출발해, 판 위를 걸어 다니는 낙서라는 지금 모습에 맞게 고치고 더했다.
- `index.html`: 판, 캐릭터, 말풍선, 대국 진행.

## 하는 법

1. **흑 · 선공** / **백 · 후공**을 고른다.
2. 내 말을 누르면 갈 수 있는 칸이 빨간 점으로 나온다. 점선 원은 잡는 칸이다.
3. **새 게임**을 누르면 다시 고른다.
4. 오른쪽 위 **규칙**을 누르면 규칙 한 장이 뜬다. 튀르크가 여백에 한마디씩 붙여 놨다. "규칙도 몰라?"부터 시작한다.

난이도는 최강 하나다. 한 수에 5초씩 실수 없이 두고, 내 차례에도 미리 생각한다.

## 튀르크

말은 연필 선을 따라 폴짝 뛰어가고, 내려앉을 때 살짝 찌그러진다. 그 선은 출발한 쪽부터 지우개로 지워지고, 옅은 지우개 자국이 남았다가 사라진다. 잡힌 말은 펜으로 박박 지워진 다음 사라진다. 말마다 찌그러진 방향이 조금씩 다르다.

머리만 보이는 흰 돔에 점 눈 두 개, 삐뚤한 입. 몸은 판 뒤로 길게 이어져 있어서 뒤뚱거려도 밑이 뜨지 않는다. 몇 초마다 판 위쪽을 따라 걸어 다니고, 말풍선이 따라온다. 생각하는 동안에는 제자리에서 들썩인다. 표정은 하나다.

## 전적

승, 패, 무승부, 연승은 이 브라우저(localStorage)에 남아서 다시 와도 이어진다. 규칙 시트 맨 아래에서 보고, 지울 수 있다. 지우려고 하면 튀르크가 한 번 꼽을 주고, 한 번 더 눌러야 지워진다. 지운 뒤에도 한마디 한다.

전적을 보고 하는 말:
- 처음 왔을 때, 하루 넘게 있다가 왔을 때 며칠 만인지와 전적
- 시작할 때 내 연승, 튀르크 연승, 10판마다 몇 번째 판인지, 전적
- 내가 처음 이겼을 때, 내 2연승 이상을 튀르크가 끊었을 때

## 언제 말하나

loa-turk 옛 버전과 같은 방식이다. 엔진이 실제로 읽은 평가값과 판 상태를 본다.

- 고를 때, 시작할 때 (흑/백, 이번 방문 전적, 연승)
- 튀르크 수 뒤: 강제 승리 발견 시 남은 수 카운트다운, 질 수순이면 당황, 내 수로 승률이 15%p 넘게 오르면 블런더, 10%p 넘게 내려가면 좋은 수 인정, 잡을 때, 두 덩어리 남았을 때, 승률 85% 넘을 때, 그 외엔 가끔 몇 수 앞 읽었는지 자랑하거나 잡담
- 내 수 뒤: 잡을 때, 내가 두 덩어리 남았을 때, 1.5초 안에 뒀을 때, 60수 넘게 갈 때
- 내 차례가 15초 넘으면 잡담, 40초 넘으면 재촉
- 끝: 이기면 몇 수 만에 끝났는지와 남은 내 덩어리 수로 놀리고 3.5초 뒤 한 번 더. 지면 버그 탓

잡담은 컴퓨터 역사, 신기한 생물, 보드게임, 우주, 수학, 공학, 바다, 인체, 말의 유래, 역사, 지구, 음식, 물리, 종이와 펜 14주제 149줄이다.

대사를 고치려면 `characters.js`의 `TALK`만 손대면 된다.

## 규칙

컴퓨터 올림피아드 규칙(2000 MSO 기준).

- 8×8 판. 흑은 위·아래 줄, 백은 왼쪽·오른쪽 줄에 6개씩. 흑이 먼저 둔다.
- 가로·세로·대각선으로 움직이고, 움직이는 칸 수는 그 줄에 놓인 말 수(양쪽 모두)와 같다.
- 내 말은 뛰어넘고 상대 말은 못 넘는다. 상대 말 칸에 멈추면 잡는다.
- 내 말 전부가 한 덩어리로 이어지면 이긴다. 한 수로 양쪽이 동시에 이어지면 무승부. 둘 수가 없으면 차례를 넘긴다. 같은 국면이 같은 차례로 세 번 나오면 무승부.
