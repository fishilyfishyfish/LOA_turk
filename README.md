# LOA 튀르크 (트래쉬토크판)

Lines of Action 엔진 **튀르크**와 두는 웹 게임. 이쪽 튀르크는 말이 많다. 수를 둘 때마다 판세를 보고 비꼰다.

브라우저로 `index.html`을 열면 된다. 설치할 것 없다.

## 파일

- `engine.js`: LOA 엔진. [loa-turk](https://github.com/fishilyfishyfish/loa-turk)의 `LoaEngine`과 자기대국으로 튜닝한 가중치를 그대로 떼어 왔다. 알파베타(PVS) 탐색, 치환표, 널무브, LMR, 반복 심화, 24개 항목 평가. 페이지가 이 함수로 Web Worker를 만들어서 생각하는 동안 화면이 멈추지 않는다.
- `characters.js`: 튀르크 후보 4명의 얼굴(SVG, 표정 4가지)과 대사.
- `index.html`: 판, 캐릭터, 말풍선, 대국 진행.

## 하는 법

1. 판 아래에서 튀르크 후보, 난이도(1~5), **흑 · 선공** / **백 · 후공**을 고른다.
2. 내 말을 누르면 갈 수 있는 칸이 점으로 나온다. 원은 잡는 칸이다.
3. **새 게임**을 누르면 다시 고른다. 판 도중에 누르면 튀르크가 한마디 한다.

난이도는 loa-turk와 같다. 1~4단계는 사람처럼 실수하고, 5단계는 한 수에 5초씩 실수 없이 둔다.

## 튀르크 후보

| 후보 | 생김새 | 말투 | 예시 |
|---|---|---|---|
| 원조 튀르크 | 1770년 체스 자동인형. 터번 쓴 나무 인형, 콧수염 | 250년 묵은 귀족 하대 ("자네") | "자네 수는 250년 전에 이미 다 봤다네." |
| 상자 속 고수 | 자동인형 상자 안에 숨어 두던 사람. 안경, 땀, 촛불 | 짜증 난 동네 고수 반말 ("야") | "그 수는 나도 못 둔다. 너무 못 둬서." |
| 고철 튀르크 | 고철로 다시 만든 로봇. 화면 얼굴에 LED 눈 | 감정 없는 척하는 로그 말투 | "반올림하면 당신의 승률은 0." |
| 커피 점쟁이 | 페즈 쓴 할아버지 점쟁이, 손에 커피 잔 | 느릿한 신비주의 반말 | "네 앞날이 아주 쓰구나. 이 커피처럼." |

## 언제 말하나

튀르크는 엔진이 실제로 읽은 평가값과 판 상태를 보고 말한다. 매 수마다 떠들지는 않는다.

| 상황 | 판단 기준 | 표정 |
|---|---|---|
| 시작 | 난이도 1·2 / 3·4 / 5에 따라 다른 대사 | 여유 |
| 다음 수에 연결 가능 | 튀르크가 바로 이을 수 있음 | 득의 |
| 강제 승리 발견 | 탐색이 몇 수 안의 승리를 찾음 (3단계 이상, 판당 한 번) | 득의 |
| 내 실수 | 내 수 뒤 튀르크 평가가 300점 넘게 오름 | 득의 |
| 튀르크가 잡음 / 내가 잡음 | 잡는 수 | 득의 / 짜증 |
| 크게 이기는 중 / 지는 중 | 평가 ±600점 넘음 | 득의 / 짜증 |
| 내가 다음 수에 연결 가능 | 내가 바로 이을 수 있음 | 놀람 |
| 오래 고민 | 내 차례가 25초 넘음 | 여유 |
| 끝 | 튀르크 승 / 내 승 / 무승부 / 도중 포기 | 각각 |

대사를 더하거나 고치려면 `characters.js`의 `lines`만 손대면 된다. `{lv}`는 난이도 이름, `{n}`은 강제 승리까지 남은 수로 바뀐다.

## 규칙

컴퓨터 올림피아드 규칙(2000 MSO 기준).

- 8×8 판. 흑은 위·아래 줄, 백은 왼쪽·오른쪽 줄에 6개씩. 흑이 먼저 둔다.
- 가로·세로·대각선으로 움직이고, 움직이는 칸 수는 그 줄에 놓인 말 수(양쪽 모두)와 같다.
- 내 말은 뛰어넘고 상대 말은 못 넘는다. 상대 말 칸에 멈추면 잡는다.
- 내 말 전부가 한 덩어리로 이어지면 이긴다. 한 수로 양쪽이 동시에 이어지면 무승부. 둘 수가 없으면 차례를 넘긴다. 같은 국면이 같은 차례로 세 번 나오면 무승부.
