# LOA 튀르크 (트래쉬토크판)

Lines of Action 엔진 **튀르크**와 두는 웹 게임. 이쪽 튀르크는 말이 많다. 판세를 보고 비꼬고, 틈나면 잡학을 늘어놓는다.

브라우저로 `index.html`을 열면 된다. 설치할 것 없다.

## 파일

- `engine.js`: LOA 엔진. [loa-turk](https://github.com/fishilyfishyfish/loa-turk)의 `LoaEngine`과 자기대국으로 튜닝한 가중치를 그대로 떼어 왔다. 알파베타(PVS) 탐색, 치환표, 널무브, LMR, 반복 심화, 24개 항목 평가. 페이지가 이 함수로 Web Worker를 만들어서 생각하는 동안 화면이 멈추지 않는다.
- `characters.js`: 튀르크 후보 5명의 얼굴(SVG, 표정 4가지)과 대사 목록. 대사는 loa-turk에서 말풍선을 빼기 전(커밋 75777c8 직전)에 있던 목록을 그대로 가져왔다. 학습판 이스터에그 대사만 뺐다.
- `index.html`: 판, 캐릭터, 말풍선, 대국 진행.
- `candidates.html`: 튀르크 후보를 표정별로 나란히 보여 주는 페이지.

## 하는 법

1. **흑 · 선공** / **백 · 후공**을 고른다.
2. 내 말을 누르면 갈 수 있는 칸이 점으로 나온다. 원은 잡는 칸이다.
3. **새 게임**을 누르면 다시 고른다.

난이도는 최강 하나다. 한 수에 5초씩 실수 없이 두고, 내 차례에도 미리 생각한다.

## 튀르크 후보

게임에는 튀르크 하나만 나온다. 지금은 `CHARS` 맨 앞(꼬마 튀르크)이 나오고, 최종 결정 전까지 `index.html?turk=<id>`로 다른 후보를 써 볼 수 있다. `candidates.html`에서 다섯을 비교한다. 대사는 모두 같다.

| id | 이름 | 생김새 |
|---|---|---|
| chibi | 꼬마 튀르크 | 1770년 자동인형을 머리 크게 줄인 꼬마. 큰 터번, 작은 콧수염 |
| kuro | 흑돌이 | 터번 쓴 LOA 흑돌 |
| cat | 냥 튀르크 | 터번 쓴 치즈 고양이 |
| robot | 깡통 튀르크 | 얼굴이 초록 화면인 작은 깡통 로봇 |
| mochi | 찹쌀 튀르크 | 터번 얹은 백돌 찹쌀떡 |

## 언제 말하나

loa-turk 옛 버전과 같은 방식이다. 엔진이 실제로 읽은 평가값과 판 상태를 본다.

- 고를 때, 시작할 때 (흑/백, 이번 방문 전적, 연승)
- 튀르크 수 뒤: 강제 승리 발견 시 남은 수 카운트다운, 질 수순이면 당황, 내 수로 승률이 15%p 넘게 오르면 블런더, 10%p 넘게 내려가면 좋은 수 인정, 잡을 때, 두 덩어리 남았을 때, 승률 85% 넘을 때, 그 외엔 가끔 몇 수 앞 읽었는지 자랑하거나 잡담
- 내 수 뒤: 잡을 때, 내가 두 덩어리 남았을 때, 1.5초 안에 뒀을 때, 60수 넘게 갈 때
- 내 차례가 15초 넘으면 잡담, 40초 넘으면 재촉
- 끝: 이기면 몇 수 만에 끝났는지와 남은 내 덩어리 수로 놀리고 3.5초 뒤 한 번 더. 지면 버그 탓

잡담은 컴퓨터 역사, 신기한 생물, 보드게임, 우주, 수학, 공학, 바다, 인체, 말의 유래, 역사, 지구, 음식, 물리 13주제 142줄이다.

대사를 고치려면 `characters.js`의 `TALK`만 손대면 된다.

## 규칙

컴퓨터 올림피아드 규칙(2000 MSO 기준).

- 8×8 판. 흑은 위·아래 줄, 백은 왼쪽·오른쪽 줄에 6개씩. 흑이 먼저 둔다.
- 가로·세로·대각선으로 움직이고, 움직이는 칸 수는 그 줄에 놓인 말 수(양쪽 모두)와 같다.
- 내 말은 뛰어넘고 상대 말은 못 넘는다. 상대 말 칸에 멈추면 잡는다.
- 내 말 전부가 한 덩어리로 이어지면 이긴다. 한 수로 양쪽이 동시에 이어지면 무승부. 둘 수가 없으면 차례를 넘긴다. 같은 국면이 같은 차례로 세 번 나오면 무승부.
